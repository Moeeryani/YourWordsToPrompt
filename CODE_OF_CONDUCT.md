# Code of Conduct

We want YourWordsToPrompt to be welcoming to beginners, contributors, researchers, and users with different levels of technical experience.

## Our standards

Be respectful and constructive. Assume good faith, give actionable feedback, and welcome questions. Disagreement about prompt design is encouraged when it stays focused on ideas and evidence.

Harassment, personal attacks, hateful content, intimidation, and publication of another person's private information are not acceptable.

## Reporting

If you see behavior that violates these standards, contact the repository maintainer privately through their GitHub profile rather than posting sensitive details in a public issue. The maintainer may remove harmful contributions, close discussions, or restrict participation as necessary.

This policy applies to project issues, discussions, reviews, and other project-managed spaces.
