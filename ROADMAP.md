# Roadmap

This is a **proposed direction**, not a list of features already shipped.

## Available now

- Copy-and-paste adaptive Master Prompt.
- Standalone Agent Skills-compatible instruction file.
- Beginner-friendly setup and representative examples.
- Contribution and quality-review guidelines.

## Next candidates

- [ ] Gather real usage reports and edge cases from different AI assistants.
- [ ] Improve examples for multilingual requests and codebase-specific tasks.
- [ ] Publish reproducible side-by-side evaluations, including failures.
- [ ] Confirm installation guidance for specific agent clients.
- [ ] Add a tiny interactive demo **only if** it adds value beyond copy/paste.
- [ ] Explore a CLI or hosted interface if users consistently request one.

## Product principles

1. New features must improve **first-time usability**, **prompt quality**, or **repeatable testing**.
2. Keep the core prompt usable without dependencies, accounts, or code.
3. Prefer genuine behavior improvements over inflated prompt length.
4. Make no unsupported claims about performance or compatibility.

Have a use case that should shape the roadmap? Open an issue describing the problem and a representative input (without secrets).
