# Roadmap

This roadmap lists **possibilities**, not shipped functionality. The maintainer's [Sovereign Adaptive Compiler](prompts/MASTER_PROMPT.md) is the authoritative behavior contract.

## Available now
- Copy-and-paste Master Prompt with task routing, complexity assessment, selective pruning, two phases, and strict output.
- Standalone Agent Skill containing the same compiler instructions.
- Beginner-friendly guide, examples, and manual quality checklist.

## Possible next steps
- [ ] Collect privacy-safe examples showing both calibration and direct compilation.
- [ ] Evaluate output-format adherence and question limits across models.
- [ ] Add multilingual examples and genuinely useful edge cases.
- [ ] Verify instructions for particular Agent Skills clients.
- [ ] Consider an interactive interface only if users need one.

## Guardrails
- Preserve the maintainer's original compiler unless a change is deliberately reviewed.
- Focus on improved usefulness, not longer prompts or extra templates.
- Mark hypothetical examples and unverified compatibility honestly.
